## Feature Highlights

### Game Modes
- Single Player (vs AI)
- Dual Player (competitive)
- Co-op (team up)
- Training Simulator
- Skeet Shooting

### Technical Features
- 6-DOF flight physics
- 60 FPS rendering
- USB gamepad support (up to 2 controllers)
- Six starfield visual effects
